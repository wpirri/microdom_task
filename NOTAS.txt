==========================================================================================
Servicio de domotica domiciliario
Se ejecuta en forma local en el hogar y gestiona las tareas en background y comunicacion
con la nube.
==========================================================================================

Crear entorno virtual:
    python -m venv microdom

Entrar a entorno virtual:
    source microdom/bin/activate

Salir de entorno virtual
    deactivate


microdom_task/
│
├── app/
│   ├── main.py
│   ├── worker.py
│   ├── config.py
│   └── __init__.py
│
├── requirements.txt
├── Dockerfile
└── k8s-deployment.yaml

docker build -t microdom-task .

docker run --rm -it \
  -e DBUSER=dompi_web \
  -e DBPASSWORD=dompi_web \
  -e DBHOST=192.168.10.32 \
  -e DBNAME=DB_DOMPIWEB \
  --name microdom-task \
  -v /etc/microdom.conf:/app/etc/microdom.conf \
  -v /var/log/microdom:/app/logs \
  -p 8081:8081 microdom-task

Daemon:
docker run --rm -it \
  -d --restart unless-stopped \
  -e DBUSER=dompi_web \
  -e DBPASSWORD=dompi_web \
  -e DBHOST=192.168.10.32 \
  -e DBNAME=DB_DOMPIWEB \
  --name microdom-task \
  -v /etc/microdom.conf:/app/etc/microdom.conf \
  -v /var/log/microdom:/app/logs \
  -p 8081:8081 microdom-task
